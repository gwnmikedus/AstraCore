{#- The "?" help toggle: a small button that shows a 1-3 sentence answer below it, with an optional "More" link (usually a glossary entry). js/help.js makes it work and AC.helpHTML() builds the same markup in the browser. Without show_label the button is a bare "?" named by `label` for screen readers; with it, `label` is visible next to the "?". `id` must be unique on the page. -#} {% macro help_toggle(id, text, label='What does this mean?', more=none, more_label='More', show_label=false) -%} {{ text }}{% if more %} {{ more_label }}{% endif %} {%- endmacro %}
