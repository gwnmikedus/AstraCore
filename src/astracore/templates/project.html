Share an idea or report a bug

Send feedback from your AstraCore account. You can review the public text before submitting. Never include login tokens, private character data, or other information you do not want published.

Hosted access remains invite-based. If you do not have access, you can still report a bug or suggest an idea on GitHub.

Contribute code or documentation

Start with the contribution guide and an existing issue, or propose an improvement before starting a larger change. Clear bug reports, reproducible examples, and documentation corrections help too.

Meet the contributors and read how CosmicCarrot started the project. GitHub contributor profiles appear automatically as work becomes part of the repository.
